<h2 align="left">Recent Projects & Achievements</h2>

###

<p align="left">
  <b>Smart Agriculture Application + AgriScan</b> — 2nd Prize-winning AI solution built for crop planning and plant health monitoring. The Smart Agriculture Application analyzes soil nutrients and weather inputs to recommend crops, provide NPK-based spray guidance, and support English/Hindi voice input. AgriScan uses YOLOv8 for plant disease detection and LangChain + ChatGroq/LLaMA-3 to generate remedy and fertilizer recommendations.
  <br><br>
  <b>EduBot – AI-Powered Educational Assistant</b> — AI assistant that processes PDF documents, extracts key insights, answers user questions using Google Gemini, and generates quizzes for interactive learning. It integrates FAISS-based vector search, NLP-based topic extraction, and a Streamlit interface for smarter document understanding and student-friendly Q&A workflows.
  <br><br>
  <b>Machine Learning-Based Security System for Office Premises</b> — Published as a research paper in IJAEMA. This project focused on secure office access using multi-factor authentication with login credentials, face recognition, OTP verification, auto-logout, auto-save, and role-based access control using Python, OpenCV/Haar Cascade, and database-backed authentication workflows.
  <br><br>
  <b>ATS Resume Analyzer using Gemini Vision</b> — AI-powered resume analysis tool that evaluates resumes against job descriptions, gives ATS match percentage, identifies missing keywords, and suggests improvements using Gemini Vision.
  <br><br>
  <b>LangGraph – Stateful Multi-AI Agents</b> — Multi-agent chatbot project using LangGraph and LangChain with tools like Wikipedia and Arxiv for context-aware responses and agentic workflows.
  <br><br>
  <b>GradPath Agent – US Study, OPT & Career Planner</b> — AI-agent project designed to help students reason through U.S. study, OPT, and career planning paths using structured guidance and AI-assisted planning.
</p>
