# 💫 About Me:
Hi, I’m Navaneet Kumar Ediga 👋<br><br>I’m a Data Scientist and AI/ML enthusiast with an M.S. in Data Science from Stevens Institute of Technology, USA, and hands-on experience in machine learning, deep learning, GenAI, NLP, analytics, and ETL workflows.<br><br>I enjoy building practical AI solutions that solve real-world problems — from AI-powered educational assistants and smart agriculture systems to ML-based security applications. My work includes developing end-to-end ML pipelines, PDF-based RAG systems, computer vision models, dashboards, and data-driven applications using Python, SQL, Scikit-learn, TensorFlow, PyTorch, Hugging Face, LangChain, Google Gemini, FAISS, FastAPI, Streamlit, Power BI, and Tableau.<br><br>Some of my key projects include EduBot, an AI-powered educational assistant for PDF understanding, Q&A, and quiz generation; Smart Agriculture Application + AgriScan, a 2nd prize-winning AI solution for crop recommendation and plant disease detection; and an ML-Based Security System for Office Premises using face recognition and secure authentication workflows.<br><br>I’m currently focused on strengthening my skills in Data Science, Machine Learning, Generative AI, LLM applications, and cloud-based AI deployment while actively exploring opportunities in Data Science, AI/ML Engineering, and Data Analytics.
